# Boîte noire Hoymiles — version 7.0.14

## Correction du bilan Linky/Dinky

- Les vues **Semaine**, **Mois** et **Année** affichent de nouveau les deux composantes de consommation Linky/Dinky : **heures pleines (HP)** et **heures creuses (HC)**.
- Lorsque l'historique graphique du Dinky omet une série HP ou HC, le logiciel complète automatiquement cette série depuis les index cumulés Linky/Dinky enregistrés localement.
- Le DDSU n'est jamais utilisé pour calculer les achats EDF du bilan.

Les historiques et réglages existants sont conservés par l'installateur.
