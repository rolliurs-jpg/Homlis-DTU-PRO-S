# Version 7.0.71 — paquet Windows de test

Le paquet réunit les dernières évolutions du tableau : bilan batterie, navigation mobile et nouvelle icône solaire. Il comprend les modules nécessaires à la surveillance DTU et DDSU.

Ce paquet n'a pas encore été installé ni validé sur un PC Windows. Vérifier le fonctionnement en lecture seule avant toute activation d'une commande de régulation. Il ne contient pas de données personnelles ni de configuration de l'installation de l'auteur. La température du Raspberry et son redémarrage concernent le tableau hébergé sur Raspberry Pi, pas un collecteur Windows.
