# Boîte noire Hoymiles v7.0.16

## Aide de sécurité — Pause maintenance

Le bouton **Pause maintenance** possède maintenant une infobulle discrète au survol de la souris.

Elle précise que :

- les lectures et relances automatiques du **DTU** sont suspendues ;
- le suivi **Linky / Dinky** continue normalement ;
- ce mode est réservé à une intervention ou une maintenance S-Miles.

Cela limite le risque d'activer ce mode par erreur sans savoir son effet.
