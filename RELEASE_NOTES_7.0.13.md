# Boîte noire Hoymiles — version 7.0.13

## Amélioration de fluidité

- Les curseurs de lecture des graphiques **production**, **bilan EDF** et **comparatif Hoymiles / Linky** sont nettement plus réactifs.
- Le graphique ne se redessine plus à chaque pixel de déplacement de la souris : il est actualisé seulement lorsque le curseur atteint une nouvelle mesure ou colonne.
- Cette amélioration réduit particulièrement les ralentissements sur les PC anciens et les historiques longs, sans modifier les données ni les calculs.

## Installation

- L'installateur Windows confirme désormais l'installation de la version **7.0.13**.
- L'édition macOS installe exactement le même programme et les mêmes optimisations de curseur.
- Les historiques, tarifs et réglages réseau locaux sont conservés lors d'une mise à jour.
