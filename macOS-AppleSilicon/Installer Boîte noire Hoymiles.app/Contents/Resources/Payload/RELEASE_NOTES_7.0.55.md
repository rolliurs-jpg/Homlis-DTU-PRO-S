# Version 7.0.55

- Le raccourci principal propose maintenant la **nouvelle interface web** ou l’**ancien logiciel avec sa fenêtre**.
- Sous Windows, le mode invisible est arrêté avant l’ouverture de l’ancienne interface.
- Sous macOS, le service invisible est suspendu pendant l’utilisation de l’ancienne interface, puis réactivé à sa fermeture lorsque le démarrage automatique est activé.
- Les réglages et les historiques existants sont conservés.
