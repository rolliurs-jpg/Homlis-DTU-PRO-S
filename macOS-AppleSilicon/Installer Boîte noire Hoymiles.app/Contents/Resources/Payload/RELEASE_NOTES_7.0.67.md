# Version 7.0.67 — logiciel classique clarifié

- La fenêtre **Équipements** précise désormais qu’elle configure uniquement
  l’ordinateur local et ne modifie jamais le Raspberry Pi.
- Les libellés sont alignés sur l’installation actuelle : **Linky / Denky D4**,
  proxy Bluetooth Hoymiles et routeur Wi-Fi solaire.
- Les trois inversions de pinces Shelly sont disponibles dans le logiciel
  classique, avec la même explication que dans le tableau web.
- Les commandes de régulation du logiciel classique sont explicitement
  indiquées comme locales, afin de ne pas les confondre avec l’automatisation
  du Raspberry Pi.
