# Boîte noire Hoymiles macOS v7.0.23

Le lanceur est maintenant installé dans `/Applications`, visible dans le dossier Applications normal du Finder. L’ancienne copie personnelle dans `~/Applications` est retirée automatiquement après une installation réussie, sans supprimer les réglages ni les historiques.

Les boutons reprennent la forme rectangulaire de la version Windows. Le contour arrondi supplémentaire, qui provoquait une double forme sur Mac, a été supprimé.
