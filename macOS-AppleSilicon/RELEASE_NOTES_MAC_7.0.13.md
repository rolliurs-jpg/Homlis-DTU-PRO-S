# Boîte noire Hoymiles macOS v7.0.13

Cette édition macOS installe le même programme Python que l'édition Windows v7.0.13.

- Curseurs des graphiques de production, bilan et comparatif optimisés.
- Moins de redessins inutiles : navigation plus fluide, notamment avec un historique long.
- Les réglages et historiques du Mac restent conservés pendant une mise à jour.
