# Version 7.0.60

- Le bouton **Ouvrir le logiciel classique** de la nouvelle interface lance maintenant réellement l’ancien logiciel sur Windows et macOS ; il ne renvoie plus vers une ancienne page web.
- Le sélecteur Windows accepte un démarrage classique direct, arrête proprement le service invisible puis libère le port 8765.
- Le lanceur macOS accepte lui aussi ce démarrage direct et conserve le choix normal entre les deux interfaces lors d’une ouverture depuis le Finder.
- Les installateurs Windows et macOS proposent la configuration du **Shelly EM Gen3 — production 2**, canal A, sans modifier les autres appareils ni les historiques.
- L’archive Mac reste autonome, sans fichiers Windows, avec droits d’exécution contrôlés avant publication.
