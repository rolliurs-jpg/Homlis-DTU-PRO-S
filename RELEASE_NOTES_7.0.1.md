# Boîte noire Hoymiles 7.0.1 — notes de version

## Version stable publique

Cette version finalise l’édition communautaire de Boîte noire Hoymiles pour le suivi local d’un DTU Pro-S et d’un Linky via Dinky 4.

### Points principaux

- Vue de production PV : direct, 24 h, hier et historique.
- Historique CSV exportable sur une plage de dates choisie.
- Bilan EDF réel basé sur les index HP/HC Linky/Dinky.
- Abonnement EDF, tarifs HP et HC réglables.
- Comparatif DTU/DDSU666 ↔ Linky/Dinky.
- Captures d’écran datées avec numéro de version.
- Installation Windows via `INSTALLER_WINDOWS.vbs`, sans fenêtre de terminal persistante.

### Important

Le DDSU666 est conservé pour la comparaison technique. Les achats EDF et le coût réel sont calculés à partir du Linky/Dinky.

### Installation

Téléchargez le ZIP du dépôt, décompressez-le, puis exécutez `INSTALLER_WINDOWS.vbs`.

Voir le [README](README.md) pour la configuration réseau DTU + Dinky.
