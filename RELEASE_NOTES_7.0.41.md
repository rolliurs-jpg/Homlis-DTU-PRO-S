# Version 7.0.41

- Le bouton **Mobile** devient **Lecture à distance** pour rendre sa fonction immédiatement compréhensible.
- Sous Windows, les adresses locale et Tailscale sont affichées avant l’ouverture du navigateur.
- Le navigateur ne masque donc plus la fenêtre contenant les adresses à utiliser sur le téléphone.
- La disposition des quatre boutons supérieurs a été ajustée pour conserver une lecture claire.
