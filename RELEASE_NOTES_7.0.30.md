# Boîte noire Hoymiles v7.0.30

## Zone d’injection plus discrète

- La coloration rouge sous 0 W est supprimée : le fond du graphique reste transparent.
- La mention **Sous 0 W : injection vers le réseau** est déplacée en bas à gauche.
- Les courbes et mesures récentes situées à droite restent ainsi entièrement lisibles.

## Valeurs indisponibles

- Une mesure de production PV ou du réseau DDSU absente est maintenant affichée comme **indisponible**.
- Le texte technique `nan` n’apparaît plus dans les indicateurs du haut.

Ces corrections sont communes aux versions Windows et macOS.
