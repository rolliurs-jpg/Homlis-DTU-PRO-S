# Version 7.0.48 — messages de surveillance clarifiés

Le tableau distingue le suivi en cours, une interruption passée et une interruption active. Il indique l’ordinateur concerné, la période et la durée d’une interruption enregistrée. Les actions proposées concernent le logiciel et sa connexion ; le message n’affirme jamais que les panneaux ont cessé de produire.

La réception d’un signal par Healthchecks n’est plus accompagnée d’une demande permanente de vérifier les notifications. Elle confirme uniquement la réception du signal, sans prétendre qu’un mail a été envoyé. L’installateur Mac autonome est conservé.
