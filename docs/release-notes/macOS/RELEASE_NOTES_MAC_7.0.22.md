# Boîte noire Hoymiles macOS v7.0.22

Cette édition utilise la même correction que Windows : notification d’injection non bloquante, maintien des mesures Dinky/Shelly pendant une pause DTU et rupture visuelle des courbes lorsqu’une période n’a pas été enregistrée.

L’installateur crée maintenant un lanceur visible sur le Bureau, propose **Lancer maintenant**, retire la quarantaine après la première validation et applique une signature locale ad hoc. Le logo des panneaux solaires devient l’icône des deux paquets macOS et les boutons de l’application sont arrondis uniquement sur Mac.
