# Boîte noire Hoymiles — v7.0.5

## Diagnostic DTU destiné au SAV Hoymiles

Cette version ajoute le bouton **Diagnostic DTU** sur toutes les pages de
l’application.

Il ouvre une page technique qui lit uniquement les informations rendues
disponibles par le DTU : mesure instantanée, version, informations,
alarmes et configuration si le firmware l’autorise. Le rapport peut être
enregistré en texte et joint à une demande de support Hoymiles.

Le diagnostic ne contient aucune commande qui modifie la limite de puissance,
le zéro-injection, le Wi-Fi, les micro-onduleurs ou le DTU.
