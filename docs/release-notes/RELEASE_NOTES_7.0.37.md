# Boîte noire Hoymiles v7.0.37

## Bleu PV sans tonalité verte

- La production PV utilise maintenant le bleu foncé pur `#00008B`.
- Cette teinte ne contient aucune composante verte et se distingue clairement du Linky/Dinky.
- La courbe, la bulle du curseur et les bilans utilisent la même couleur.

Cette amélioration est commune aux versions Windows et macOS.
