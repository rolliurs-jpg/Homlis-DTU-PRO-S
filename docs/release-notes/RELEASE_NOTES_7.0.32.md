# Boîte noire Hoymiles v7.0.32

## Groupe Shelly en jaune très foncé

- La production mesurée par le Shelly abandonne le violet et passe en jaune très foncé.
- Le réseau EDF mesuré par le Shelly utilise le même jaune très foncé.
- Les deux mesures restent différenciées par la forme de leur trait.
- Les deux lignes correspondantes de la bulle du curseur adoptent également ce jaune.

Cette amélioration est commune aux versions Windows et macOS.
