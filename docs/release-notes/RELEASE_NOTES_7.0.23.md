# Boîte noire Hoymiles v7.0.23

## Installation macOS clarifiée

- Le lanceur est désormais installé dans le dossier Finder standard `/Applications`.
- L’ancienne copie créée dans `~/Applications` est supprimée sans toucher aux historiques ni aux réglages.
- Le programme et ses données restent rangés dans `~/Library/Application Support/BoiteNoireHoymiles` ; seul le lanceur apparaît dans Applications.
- Le raccourci du Bureau pointe vers l’unique application installée.

## Interface macOS

- Les boutons arrondis ajoutés en 7.0.22 ont été retirés.
- Windows et macOS utilisent de nouveau les mêmes boutons rectangulaires, sans double contour.
