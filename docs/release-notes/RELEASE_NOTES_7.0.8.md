# Boîte noire Hoymiles v7.0.8

## Demande SAV jointe aux preuves

Le rapport **Diagnostic DTU** contient désormais une demande explicite au SAV Hoymiles :

1. confirmer la réception ;
2. indiquer le résultat de l'analyse DTU / DDSU / Linky ;
3. préciser les corrections, actions ou réglages éventuellement appliqués.

Chaque export d'historique CSV conserve son format compatible Excel/LibreOffice et crée, dans le même dossier, un fichier compagnon `*_demande_sav_hoymiles.txt` avec cette demande, la période, le nombre de mesures, la date et la version du logiciel.

Adresse de réponse indiquée : `rolli.urs@free.fr`.
