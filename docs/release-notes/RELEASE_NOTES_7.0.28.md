# Boîte noire Hoymiles v7.0.28

## Curseur plus lisible

- La boîte de valeurs est descendue entièrement dans le graphique.
- Elle ne recouvre plus le titre, la légende ni les boutons supérieurs.
- Son fond est presque opaque afin de masquer les courbes et textes situés derrière.
- Les couleurs des groupes de sources restent visibles dans la boîte.

Cette amélioration est commune aux versions Windows et macOS.
