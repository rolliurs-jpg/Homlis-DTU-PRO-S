# Boîte noire Hoymiles v7.0.36

## Production PV en bleu foncé

- La production PV passe du bleu ciel au bleu foncé.
- Cette couleur est appliquée à la courbe principale, à la bulle du curseur et aux graphiques de bilan.
- Toutes les autres couleurs restent inchangées.

Cette amélioration est commune aux versions Windows et macOS.
