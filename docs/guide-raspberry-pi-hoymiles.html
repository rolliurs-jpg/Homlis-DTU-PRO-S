GUIDE PRATIQUE · COLLECTEUR LOCAL PERMANENT

Installer un suivi solaire Hoymiles sur Raspberry Pi.

Le Raspberry Pi collecte les mesures en continu et met le tableau à disposition sur votre réseau privé. Les téléphones et ordinateurs consultent ensuite la même interface, sans créer de seconde lecture sur les appareils solaires.

Le rôle du Raspberry Pi

Il remplace un ordinateur laissé allumé : il conserve l’historique, démarre automatiquement après une coupure et héberge le tableau web local. Il ne publie pas les mesures sur Internet.

Ce qu’il faut préparer

  • Un Raspberry Pi relié au réseau domestique, avec Raspberry Pi OS et un compte utilisateur.
  • Une connexion réseau vers les appareils réellement utilisés : DTU Pro-S, Linky/Denky D4, Shelly et batterie sont optionnels.
  • Les adresses locales des appareils, idéalement réservées dans la box Internet.
  • Un seul collecteur actif : si le Raspberry assure le suivi, le logiciel Mac ou Windows doit seulement ouvrir son tableau web.

Installer le collecteur

  1. Téléchargez l’archive Raspberry Pi depuis la page GitHub du projet, puis décompressez-la dans le dossier de votre choix.
  2. Ouvrez un terminal sur le Raspberry et lancez l’installateur fourni : bash raspberry-pi/INSTALLER_RASPBERRY.sh.
  3. Renseignez uniquement les équipements présents dans la configuration locale. Les mots de passe, adresses IP et historiques ne doivent jamais être publiés dans GitHub.
  4. Vérifiez que le service démarre avec systemctl is-active boite-noire-hoymiles. Le résultat attendu est active.

Important : le service Raspberry fonctionne normalement sans fenêtre graphique. C’est volontaire : le suivi reste actif même si aucun écran n’est branché.

Ouvrir le tableau depuis le réseau local

Depuis un Mac, un PC ou un téléphone connecté au même Wi-Fi, ouvrez l’adresse suivante en remplaçant l’adresse par celle du Raspberry :

http://ADRESSE_IP_DU_RASPBERRY:8765

Si vous utilisez le bureau distant du Raspberry, ouvrez Chromium puis utilisez http://localhost:8765. Cette page est le tableau du collecteur, pas une application de bureau distincte.

Vérifier le bon fonctionnement

À vérifierCe que cela signifie
Service actifLe collecteur enregistre et répond après un redémarrage du Raspberry.
Dernière mesure récenteLe tableau reçoit des données ; la nuit, une production à 0 W reste normale.
Équipements visiblesLe tableau précise si le DTU, le Shelly, le Linky ou la batterie sont joignables.
Historique CSVLes bilans sont calculés à partir des mesures réellement conservées, sans combler les trous.

Accès hors de la maison

Pour consulter le tableau à distance, utilisez un réseau privé Tailscale entre vos appareils et le Raspberry. N’ouvrez pas le port 8765 de la box Internet et n’utilisez pas un lien public pour un tableau contenant les données de votre maison.
