NOUVEAU · ALARMES DU SUIVI

Ne découvrez plus une interruption plusieurs heures après.

Après cinq minutes sans mesure valide enregistrée, le logiciel affiche une alarme. Le tableau mobile ouvert signale aussi une perte de connexion, sur le Wi-Fi ou via Tailscale. Une production à 0 W pendant la nuit reste une mesure normale.

Pour être averti même ordinateur éteint ou téléphone verrouillé, configurez une notification extérieure par mail avec Healthchecks. Les interruptions et reprises sont enregistrées localement.

  1. 1. Un contrôle par ordinateurCréez un contrôle Mac et un contrôle Windows sur Healthchecks. Réglez Period à 1 minute et Grace Time à 4 minutes.
  2. 2. Enregistrez l’URL privéeDans Alarmes, collez l’URL de ping du contrôle : Ctrl+V sur Windows, ⌘+V sur Mac. Un encadré vert confirme l’enregistrement. Ce n’est pas l’adresse IP du tableau mobile.
  3. 3. Activez les mailsAjoutez Email dans Intégrations, confirmez l’adresse et associez-la aux contrôles. Vérifiez le premier ping puis le mail de test. Les SMS sont facultatifs et soumis au quota de votre offre.
  4. 4. Vérifiez une vraie interruptionLors d’un créneau choisi, arrêtez le logiciel plus de cinq minutes, vérifiez le mail, puis relancez. Une panne Internet ou électrique peut produire la même alerte. Mettez le contrôle en pause pour une maintenance volontaire.

INSTALLATION WINDOWS, MAC ET RASPBERRY PI

Installez, choisissez le réseau, surveillez.

Pour un suivi permanent, installez le collecteur sur Raspberry Pi : les ordinateurs et téléphones ouvrent ensuite son tableau privé.

  1. 1. Raspberry Pi recommandéSuivez le guide Raspberry Pi pour installer le service systemd et conserver la collecte jour et nuit.
  2. 2. InstallezDouble-cliquez sur INSTALLER_WINDOWS.vbs.
  3. 3. ChoisissezDeux connexions Wi-Fi, ou réseau unique nano-routeur/LAN recommandé.
  4. 4. Shelly facultatifSaisissez son IP si présent. Lors d’une mise à jour, « Non » conserve ses réglages actuels.
  5. 5. Choisissez l’interfaceLe raccourci Boîte noire Hoymiles propose la nouvelle interface web ou l’ancien logiciel avec sa fenêtre, sur Windows comme sur Mac.
  6. 6. Mac Apple SiliconTransférez l’archive TAR.GZ intacte sur le Mac et décompressez-la sur le Mac. Ce format conserve les autorisations d’exécution. Le dossier contient seulement 1 - INSTALLER BOITE NOIRE HOYMILES.app et 2 - LIRE-MOI-MAC.txt. Faites un clic droit sur l’installateur puis choisissez Ouvrir.
    Version non testée sur Mac Intel.
  7. 7. Démarrage automatique RaspberryLaissez le réglage web « Démarrage automatique » sur Non : systemd lance déjà le collecteur Raspberry au démarrage.
macOS 15.5 ou plus récent — erreur « No route to host »

Si les appareils répondent depuis Terminal mais restent hors ligne dans l’application, autorisez le réseau Wi-Fi local puis redémarrez le Mac :

sudo defaults write com.apple.network.local-network AllowedWiFiLocalNetworkAddresses -array-add "192.168.1.0/24"

Cette exception système concerne toutes les applications utilisant le réseau 192.168.1.x. Procédure validée sous macOS 27.0. Explication officielle Apple.

ANDROID, iOS, macOS, WINDOWS ET TAILSCALE

Surveillez la maison, même en vacances.

Le Raspberry Pi héberge le tableau privé. Ouvrez-le dans Chrome (Android), Safari (iPhone/iPad), Safari/Chrome (Mac) ou Edge/Chrome (Windows). Tailscale crée un accès privé et chiffré à distance.

  1. 1. Lancez un seul collecteurLe Raspberry Pi collecte les données et sert le tableau sur le port 8765. Ne lancez pas en parallèle la gestion solaire sur Mac ou Windows.
  2. 2. À la maisonOuvrez http://IP_DU_RASPBERRY:8765/ sur le Wi-Fi local.
  3. 3. Installez TailscaleConnectez le Raspberry et chaque téléphone/ordinateur au même tailnet.
  4. 4. Consultez à distanceOuvrez http://IP_TAILSCALE_DU_RASPBERRY:8765/, puis ajoutez la page à l’écran d’accueil Android ou iPhone. Sur Raspberry, obtenez l’adresse avec tailscale ip -4. Aucun port de la box ni service public Funnel n’est nécessaire.

Le tableau indique l’âge et la provenance de chaque mesure. N’ouvrez aucun port sur la box, n’utilisez pas Tailscale Funnel, activez la double authentification du compte Tailscale et protégez les ESP32 en WPA2/WPA3. Sur téléphone, Windscribe peut remplacer temporairement Tailscale : coupez Windscribe puis réactivez Tailscale si l’accès privé ne revient pas automatiquement.

DTU + DINKY + SHELLY : DEUX OPTIONS RÉSEAU

La bonne connexion pour chaque équipement.

Windows : deux connexions Wi-Fi

Le Wi-Fi interne relie le PC à la box, au Dinky et au Shelly. Une seconde antenne Wi-Fi relie le PC au Wi-Fi propre du DTU.

Linky → Dinky 4 → Wi-Fi de la box → PC
DTU Pro-S → Wi-Fi dédié → 2e Wi-Fi du PC

Windows et Mac : réseau unique recommandé

Le DTU rejoint la box par un nano-routeur en mode Client/Pont ; Dinky et Shelly restent sur le même LAN. C’est l’unique configuration proposée sur Mac.

Linky → Dinky 4 → Box ← Shelly Pro EM
DTU Pro-S → Ethernet → nano-routeur → Box → PC / Mac

Passerelle économique conseillée

Le TP-Link TL-WR802N suffit largement pour le faible débit du DTU : mode Client/Pont, un port Ethernet et alimentation USB. Son prix se situe généralement autour de 25 à 35 €. Choisissez Client puis Smart IP (DHCP) afin de laisser la box attribuer les adresses.

DTU Ethernet → TL-WR802N en mode Client → Wi-Fi 2,4 GHz de la box

Alternative bi-bande

Le TP-Link TL-WR902AC ajoute le Wi-Fi 5 GHz, mais il est plus cher et n’apporte aucun gain nécessaire au DTU. Il peut être choisi si le réseau 2,4 GHz est très encombré.

Ces modèles sont des suggestions techniques indépendantes : le projet n’est pas affilié à TP-Link et ne reçoit aucune commission.

QUESTIONS ESSENTIELLES

Ce que fait — et ne fait pas — le logiciel.

Le logiciel pilote-t-il le zéro injection ?

Non. Le zéro injection reste configuré et piloté par le DTU / S-Miles Cloud. L’application observe le Shelly, alerte après une injection durable, cumule les pertes en Wh/kWh et exporte les preuves.

Pourquoi comparer le DDSU au Linky ?

Le DDSU est utile pour le système Hoymiles mais peut différer du compteur. Le Linky/Dinky est la référence retenue pour suivre les achats EDF.

Mes données partent-elles sur Internet ?

Non. Les historiques, réglages et exports restent locaux sur votre ordinateur. GitHub sert uniquement à diffuser le logiciel.

Choisissez vos équipements

Avec le DTU Hoymiles : Dinky seul pour les index Linky, Shelly Pro EM seul pour les mesures indépendantes, ou les deux ensemble. Le bouton Équipements permet d’activer les appareils utilisés et de renseigner leurs adresses. Après enregistrement, relancez le logiciel.

Courbes, bulles et cartes mobiles s’adaptent au choix. Un appareil en panne reste visible. Avec le Shelly seul, le bilan est une estimation sur les mesures enregistrées ; avec le Dinky, il utilise les index Linky. Les mesures réseau ne sont jamais additionnées.
