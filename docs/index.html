INSTALLATION WINDOWS

Installez, choisissez le réseau, surveillez.

L’installation est pensée pour rester simple. Elle ne laisse pas de terminal ouvert et conserve vos historiques locaux lors d’une mise à jour.

  1. 1. TéléchargezRécupérez le ZIP du projet depuis GitHub et décompressez-le.
  2. 2. InstallezDouble-cliquez sur INSTALLER_WINDOWS.vbs.
  3. 3. ChoisissezDTU-WIFI pour deux cartes Wi-Fi, ou DTU-LAN pour placer les appareils sur le réseau de la box.
  4. 4. Shelly facultatifSaisissez son IP si présent. Lors d’une mise à jour, « Non » conserve ses réglages actuels.
  5. 5. LancezUtilisez le raccourci Boîte noire Hoymiles créé sur le Bureau.
  6. 6. Mac Apple SiliconOuvrez macOS-AppleSilicon/Installer Boîte noire Hoymiles.app. La version 7.0.22 propose séparément DTU, Dinky et Shelly et conserve les réglages lors d’une mise à jour. Autorisez ensuite l’accès au réseau local dans macOS.
    DTU-WIFI est expérimental et demande un second adaptateur Wi-Fi compatible macOS.
    Version non testée sur Mac Intel.

DTU + DINKY + SHELLY : DEUX OPTIONS RÉSEAU

La bonne connexion pour chaque équipement.

Deux réseaux Wi-Fi simultanés

Le Dinky est sur la box et le PC / Mac le consulte par le Wi-Fi de la box. Le DTU diffuse son propre Wi-Fi : utilisez une seconde carte Wi-Fi (souvent USB) pour le DTU. Cette configuration est expérimentale sur Mac.

Linky → Dinky 4 → Wi-Fi de la box → PC / Mac
DTU Pro-S → Wi-Fi dédié → 2e Wi-Fi du PC / Mac

Un seul réseau local — recommandé

Le DTU rejoint la box en Ethernet direct ou par une passerelle en mode pont Wi-Fi ; Dinky et Shelly restent sur le même LAN. Le pont ne doit créer ni second réseau ni double NAT.

Linky → Dinky 4 → Box ← Shelly Pro EM
DTU Pro-S → Ethernet → pont Wi-Fi → Box → PC / Mac

Passerelle économique conseillée

Le TP-Link TL-WR802N suffit largement pour le faible débit du DTU : mode Client/Pont, un port Ethernet et alimentation USB. Son prix se situe généralement autour de 25 à 35 €. Choisissez Client puis Smart IP (DHCP) afin de laisser la box attribuer les adresses.

DTU Ethernet → TL-WR802N en mode Client → Wi-Fi 2,4 GHz de la box

Alternative bi-bande

Le TP-Link TL-WR902AC ajoute le Wi-Fi 5 GHz, mais il est plus cher et n’apporte aucun gain nécessaire au DTU. Il peut être choisi si le réseau 2,4 GHz est très encombré.

Ces modèles sont des suggestions techniques indépendantes : le projet n’est pas affilié à TP-Link et ne reçoit aucune commission.

BILAN EDF

Le Linky pour les kWh et les euros.

Le calcul HP, HC et abonnement s’appuie sur les index Linky/Dinky, et non sur le DDSU.

QUESTIONS ESSENTIELLES

Ce que fait — et ne fait pas — le logiciel.

Le logiciel pilote-t-il le zéro injection ?

Non. Le zéro injection reste configuré et piloté par le DTU / S-Miles Cloud. L’application observe le Shelly, alerte après une injection durable, cumule les pertes en Wh/kWh et exporte les preuves.

Pourquoi comparer le DDSU au Linky ?

Le DDSU est utile pour le système Hoymiles mais peut différer du compteur. Le Linky/Dinky est la référence retenue pour suivre les achats EDF.

Mes données partent-elles sur Internet ?

Non. Les historiques, réglages et exports restent locaux sur votre ordinateur. GitHub sert uniquement à diffuser le logiciel.
